    Frontend: group code by feature
    
    Move the frontend from layer folders (components/, services/, store/slices/)
    to feature folders under src/features/, with shared building blocks in
    src/lib/ and the app composition in src/app/.
    
    Each feature has the same shape: ui/ for React, service, state, a typed
    client for its Tauri commands, a model, and an index.ts as its public API
    (ui/index.ts for views). Native calls now go through client.ts files, and
    large components and hooks are split below 300 (.tsx) and 400 (.ts) lines.
    
    src/boundaries.test.ts enforces the rules with shrinking allowlists:
    Tauri only from clients, features reach each other through index.ts,
    lib/ and the harness stay below features, React stays in ui/, and file
    size limits. scripts/move-module.mjs moves files and rewrites imports.
    
    The Rust host reads the workflow starter files from their new location
    (src/features/workflows/starter).
